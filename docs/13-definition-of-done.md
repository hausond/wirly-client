# Definition of Done

Статус: **действует**. Единый чек-лист для любого изменения, включая
документацию и конфигурацию.

## 1. Продукт

- [ ] поведение соответствует задаче и [уставу](00-charter.md);
- [ ] нет расширения рамок без согласования;
- [ ] обратная совместимость сохранена или оформлен breaking change.

## 2. Код

- [ ] соответствует [стандартам](02-code-standards.md);
- [ ] нет `unsafe` без ADR;
- [ ] нет `unwrap`/`expect`/`panic!` в библиотеках;
- [ ] ошибки типизированы и не глотаются;
- [ ] нет `#[allow]` без `WHY:` и issue;
- [ ] публичный API документирован (`///`);
- [ ] нет новых зависимостей без обоснования и проверки лицензии.

## 3. Тесты

- [ ] новое поведение покрыто unit-тестами;
- [ ] граничные случаи и ошибки покрыты;
- [ ] покрытие строк 100% (`crates/**`);
- [ ] patch coverage 100%;
- [ ] багфикс сопровождается регрессионным тестом;
- [ ] тесты детерминированы (без сети/сна в unit);
- [ ] нет `#[ignore]` без issue.

## 4. Гейты

- [ ] `cargo fmt --check`;
- [ ] `cargo clippy -D warnings`;
- [ ] `cargo test --workspace`;
- [ ] `cargo llvm-cov ... --fail-under-lines 100`;
- [ ] `cargo deny check`;
- [ ] `cargo audit`;
- [ ] `cargo doc` без предупреждений.

## 5. Документация

- [ ] обновлены затронутые документы;
- [ ] ADR добавлен, если решение архитектурное;
- [ ] CHANGELOG обновлён (для пользовательских изменений);
- [ ] примеры/схемы актуальны.

## 6. Git

- [ ] ветка по правилам;
- [ ] коммиты по Conventional Commits;
- [ ] PR ≤ 400 строк, один смысл;
- [ ] описание по шаблону;
- [ ] все обсуждения закрыты.

## 7. Безопасность

- [ ] нет секретов в коде/логах;
- [ ] IPC валидируется;
- [ ] нет ослабления TLS/REALITY;
- [ ] kill switch не обходится;
- [ ] новые крипто-зависимости согласованы.

## 8. Наблюдаемость

- [ ] логи структурированы и без приватных данных;
- [ ] метрики добавлены для нового поведения (если применимо);
- [ ] ошибки содержат контекст.

## 9. Финальный вопрос

> Смогу ли я через год без объяснений автора понять, почему это сделано так,
> и безопасно ли это менять?

Если «нет» — изменение не готово.
