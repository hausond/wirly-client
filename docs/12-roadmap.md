# Дорожная карта

Статус: **действует**. Фаза не начинается, пока не выполнены критерии выхода
предыдущей. Даты не обещаются, обещаются критерии.

## M0 — Фундамент (текущая)

**Цель:** каркас, который нельзя «сломать архитектурно».

Состав:

- workspace, крейты, границы зависимостей;
- модели профилей, правила роутинга, пресеты;
- fake-IP пул;
- CI, гейты, документация, hooks.

**Критерии выхода:**

- [x] `cargo build/clippy/fmt/test` зелёные;
- [x] покрытие `crates/**` 100%;
- [x] 4 пресета + тестовая матрица;
- [x] документация полная, ADR заведены;
- [x] все проверки обязательны в GitHub (branch protection: 8 required checks,
      линейная история, запрет force-push, запрет прямых пушей);
- [x] гейт покрытия 100% на каждый крейт зелёный в CI.

## M1 — Вертикальный срез

**Цель:** реальный трафик через собственный TUN и один протокол.

Состав:

- `wintun` + чтение/запись пакетов;
- userspace-стек (smoltcp) + маршруты + DNS fake-IP;
- WireGuard (`boringtun`);
- служба + IPC + минимальный UI (Slint);
- kill switch (базовая версия).

**Критерии выхода:**

- подключение к реальному серверу, `api.ipify.org` показывает сервер;
- разрыв туннеля не пропускает трафик напрямую (тест);
- покрытие 100%, E2E-прогон зелёный;
- восстановление маршрутов после падения службы.

## M2 — Роутинг как продукт

**Цель:** пресеты работают на практике, ими можно управлять.

Состав:

- process-matching (Windows);
- импорт подписок и share-ссылок в UI;
- редактор пресетов;
- rule-set'ы (свой JSON + импорт Clash/sing-box);
- статистика по клиентам/правилам.

**Критерии выхода:**

- кейс «WoW напрямую, остальное в туннель» воспроизводится правилами;
- смена пресета на лету без переподключения;
- тесты на приоритеты и конфликты правил.

## M3 — Совместимость и REALITY

**Цель:** работать с существующей инфраструктурой Xray.

Состав:

- VLESS WS/TLS, Trojan, Shadowsocks-2022;
- VLESS + REALITY (BoringSSL/uTLS);
- interop-тесты против Xray.

**Критерии выхода:**

- профили из панели 3x-ui импортируются без ручной правки;
- REALITY проходит interop с Xray 26.x (проверено на реальном сервере);
- негативные тесты (неверный ключ/shortId/SNI).

## M4 — Скорость и удобство

**Состав:**

- Hysteria2, TUIC, AmneziaWG;
- автообновление, подпись, SBOM;
- трей, горячие клавиши, локализация;
- диагностические пакеты.

**Критерии выхода:**

- стабильные релизы 3 месяца без P0;
- метрики успешных подключений ≥ 99%;
- время подключения ≤ 3 с.

## Правила дорожной карты

- Нельзя начинать M3, не закрыв M1.
- Любая «плюс-фича» вне фаз — только через изменение устава.
- Если критерий выхода не выполнен, фаза не закрывается; перенос дат
  не является выполнением.
