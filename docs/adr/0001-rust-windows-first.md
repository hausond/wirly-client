# ADR 0001: Rust и Windows-first

- Статус: принято
- Дата: 2026-11-06
- Контекст: выбор языка и первой платформы

## Контекст

Нужен нативный VPN-клиент, который мы полностью контролируем, без Go-рантайма
и с предсказуемым поведением на Windows. Основной пользователь — Windows 10/11.

## Решение

- Основной язык — Rust (edition 2021).
- Первая и единственная платформа v1 — Windows x64.
- macOS/Linux/мобильные — вне рамок v1 (см. устав).
- UI — Slint (Rust-first), без web-фронтенда.

## Последствия

**Плюсы:** memory safety, единый бинарь, хорошая экосистема сетевых крейтов,
отсутствие рантайма.

**Минусы:** macOS потребует Swift/Network Extension; часть протоколов
придётся реализовывать самостоятельно.

## Альтернативы

- Go + sing-box как библиотека: быстрее, но GPL и чужой рантайм.
- C++/Qt: выше стоимость поддержки и риск UB.
- Electron/Tauri UI: front-end не на Rust, противоречит цели.
