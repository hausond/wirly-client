# ADR 0002: Разделение службы и UI

- Статус: принято
- Дата: 2026-11-06
- Контекст: привилегии и безопасность

## Контекст

TUN, маршруты и WFP требуют административных прав. Запускать UI с правами
администратора — недопустимый риск (браузерный движок, сторонние библиотеки).

## Решение

- `vpn-service` — Windows-служба под SYSTEM, владеет TUN/DNS/маршрутами/секретами.
- `vpn-desktop` — непривилегированный UI, общается со службой по named pipe.
- IPC: строгая схема сообщений (`vpn-ipc`), валидация на стороне службы,
  DACL только для текущего пользователя и SYSTEM.

## Последствия

**Плюсы:** поверхность атаки минимальна, UI можно обновлять независимо,
служба переживает перезапуск UI.

**Минусы:** больше кода (IPC, состояния), сложнее отладка.

## Инварианты

- UI никогда не получает секреты в открытом виде.
- UI не может выполнить произвольную команду в службе.
- Падение UI не рвёт туннель.
