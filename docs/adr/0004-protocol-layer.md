# ADR 0004: Слой протоколов и лицензии

- Статус: принято
- Дата: 2026-11-06
- Контекст: объём работ, зависимости, юридическая чистота

## Контекст

«Все современные протоколы на Rust» — большой объём. Часть протоколов
имеет зрелые Rust-реализации, часть — только Go (Xray, sing-box, mihomo).

## Решение

- Ядро туннеля не знает о протоколах: только trait `Outbound`.
- Каждый протокол — отдельный модуль `vpn-proto`.
- Используем готовые крейты там, где лицензия позволяет:
  `boringtun` (BSD-3), `shadowsocks-rust` (MIT).
- Не портируем код из GPL-проектов (`sing-box`, `mihomo`).
  `Xray` (MPL-2.0) — только как источник спецификации, не как код.
- Отсутствующие реализации пишем сами, начиная с самых востребованных.

## Последствия

**Плюсы:** чистая лицензия, контроль качества, отсутствие чужого рантайма.

**Минусы:** VLESS/REALITY/Hysteria2/TUIC требуют собственной реализации;
сроки растягиваются (см. дорожную карту).

## Правила

- Новая протокольная зависимость проходит `cargo-deny` и ревью security.
- REALITY — только на BoringSSL с interop-тестами против Xray.
- Любое отклонение — новый ADR.
