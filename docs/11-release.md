# Релизы и версионирование

Статус: **действует**.

## 1. Semver

- `MAJOR` — несовместимый формат конфигов/пресетов, ломающее изменение API.
- `MINOR` — новая функциональность, обратная совместимость.
- `PATCH` — исправления без изменения поведения.

Версионируются независимо:

- клиент (`vX.Y.Z`);
- `schema_version` пресетов;
- формат share-ссылок (обратная совместимость обязательна).

## 2. Каналы

| Канал | Источник | Частота |
|---|---|---|
| `dev` | любой зелёный `main` | по коммиту |
| `beta` | тег `vX.Y.Z-beta.N` | по готовности |
| `stable` | тег `vX.Y.Z` | по релизному чек-листу |

## 3. Релизный чек-лист

Перед тегом:

- [ ] все гейты зелёные на `main`;
- [ ] покрытие 100%;
- [ ] нет открытых блокирующих issues;
- [ ] `cargo audit` / `cargo deny` — чисто;
- [ ] CHANGELOG обновлён;
- [ ] документация актуальна (версии, скриншоты);
- [ ] E2E-прогон на реальном сервере пройден;
- [ ] проверены upgrade и downgrade конфигов;
- [ ] бинарник подписан, хеш опубликован;
- [ ] проверен размер и отсутствие отладочных символов.

## 4. Артефакты

- `hausond-vpn-setup-X.Y.Z.exe` (подписан);
- `hausond-vpn-X.Y.Z.zip` (portable);
- `SHA256SUMS` + подпись;
- SBOM (`cargo cyclonedx`).

## 5. Откат

- Откат — установка предыдущей версии; конфиги мигрируются обратно
  только если версия схемы совместима.
- При несовместимости — предупреждение и резервная копия перед обновлением.
- Критический баг → `hotfix` → внеочередной `PATCH`.

## 6. Совместимость

- Новый клиент читает конфиги предыдущей мажорной версии.
- Старый клиент не обязан читать новые конфиги; при этом обязан отказаться
  с понятной ошибкой, а не падать.

## 7. Подпись и обновления

- Обновления проверяют подпись и хеш до установки.
- Канал обновления — только HTTPS с pinning.
- Автообновление можно отключить в настройках.
