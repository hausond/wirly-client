# Наблюдаемость и приватность

Статус: **действует**.

## 1. Логи

- Библиотека: `tracing`; бинарники настраивают subscriber.
- Уровни:

| Уровень | Когда |
|---|---|
| `error` | операция не выполнена, требуется действие |
| `warn` | деградация, повтор, восстановление |
| `info` | жизненный цикл (старт, подключение, смена профиля) |
| `debug` | диагностика для разработчика |
| `trace` | только локально, по флагу |

- Сообщения структурированы: `tracing::info!(profile = %id, outbound = %name, "connected")`.
- Запрещено: пароли, ключи, UUID, полные IP, содержимое пакетов, домены
  пользователя в `info` (только в `debug` и с маской).

## 2. Метрики

Локальные (без отправки наружу):

| Метрика | Тип | Назначение |
|---|---|---|
| `session.state` | gauge | текущее состояние |
| `connect.attempts` | counter | число попыток |
| `connect.success` | counter | успешные |
| `connect.latency_ms` | histogram | время до готовности |
| `traffic.up_bytes` / `down_bytes` | counter | трафик |
| `routing.decisions{action}` | counter | распределение решений |
| `errors{kind}` | counter | типы ошибок |

Правила:

- метрики не содержат пользовательских данных;
- агрегация — в памяти, выгрузка — только по явному согласию.

## 3. Трассировка

- `tracing` spans для: `session`, `connect`, `dial`, `route`.
- В E2E-тестах — сбор spans в файл.
- В релизе — только `info`+; `debug` включается флагом `--debug-log`.

## 4. Диагностический пакет

По запросу пользователя формируется zip:

- версия клиента и ОС;
- последние N строк логов (без приватных данных);
- конфигурация без секретов (маскирование);
- результат `ipconfig /all` (без MAC-адресов);
- статус службы.

Пакет **никогда** не отправляется автоматически.

## 5. Краш-репорты

- По умолчанию выключены.
- При включении: opt-in, без дампов памяти, только backtrace и версия.

## 6. Метрики качества

В CI/релизе отслеживаются:

- покрытие;
- время сборки;
- размер бинарника;
- результаты бенчмарков;
- число открытых security-алертов.

## 7. Запрещено

- Логировать тела пакетов и заголовки целиком.
- Отправлять телеметрию без согласия.
- Хранить логи дольше 7 дней по умолчанию.
- Писать в лог полный IP (маска: `1.2.3.x`).
